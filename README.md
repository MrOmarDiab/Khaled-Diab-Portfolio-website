# Khaled Diab Portfolio Website

## Getting started

This is a Vite + React + TypeScript portfolio site.

Prerequisites:
- Node.js 18+ and npm

Install and run:

```sh
# Step 1: Clone the repository.
git clone https://github.com/MrOmarDiab/Khaled-Diab-Portfolio-website.git

# Step 2: Navigate to the project directory.
cd Khaled-Diab-Portfolio-website

# Step 3: Install dependencies.
npm i

# Step 4: Start the dev server.
npm run dev
```

## Tech stack

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Deployment

Build the production bundle:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```
